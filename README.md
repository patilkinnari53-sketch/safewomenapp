# 🛡️ SafeHer - Women Safety Web Application

A full-stack web application to help women stay safe with instant SOS alerts, live location sharing, and emergency contacts.

## 🚀 Tech Stack
- **Frontend**: React, React Router, Axios
- **Backend**: Java, Spring Boot, Spring Security, JWT
- **Database**: H2 (in-memory for development)

## ✨ Features
- 🔐 User Registration & JWT Login
- 🚨 One-tap SOS with live location
- 👥 Emergency Contact Management
- 📍 Live Location Sharing
- 📜 Alert History
- 🆘 National Helpline Quick Access
